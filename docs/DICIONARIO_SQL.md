# Dicionário de Dados - PRF 2025

**uf** uf de onde ocorreu o acidente (Ex: SP, RJ, PE)
**municipio** Município do acidente (Ex: São Paulo, Rio de Janeiro, Recife)
**mortos** Número de mortos registrados na ocorrência (Ex: 0, 1, 2)
**fase_dia** Fase do dia em que se deu o acidente (Ex: Pleno dia, Plena Noite, Amanhecer)
**tipo_pista** Tipo da pista (Ex: Simples, Dupla, Múltipla) |
**causa_acidente** Causa principal registrada pela PRF (Ex: Reação tardia do condutor, Velocidade incompatível, Ingestão de álcool)
**tipo_acidente** Tipo do acidente (Ex: Colisão frontal, Colisão traseira, Tombamento)
**acidente_fatal** Variável criada pela equipe (1 se houve óbito, 0 caso contrário)
